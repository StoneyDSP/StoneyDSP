# StoneyDSP documentation

@mainpage StoneyDSP

StoneyDSP is a portable C and C++ audio-DSP library intended for use by
separately maintained products. It owns reusable numerical and DSP behaviour,
public headers, package exports, and portability validation. It does not own
JUCE host integration, product UI, browser rendering, presets, or commercial
release code.

The human-maintained documents below are the source of truth for project
intent. Generated Doxygen HTML under `build/doc/html/` is a rendered view, not
an editable source.
